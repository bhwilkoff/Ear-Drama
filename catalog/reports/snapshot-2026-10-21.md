# The catalog snapshot of 2026-10-21

> This was `dist/README.md` beside the split data parts in Archive Watch. The
> parts are now joined on the `catalog-2026-10-21` Release (`radio-catalog.sqlite.xz`,
> `harvest-cache.tar.xz`); restore them as `catalog/README.md` says. The
> commands below that `cat` the `.part` files describe the old split form.

Owner, 2026-10-19: *"Please do what you can to fully research every audio file,
episode, and piece of metadata we have or that is available to you on the web.
We want the most complete database possible before we start designing and
implementing the app."* Built after all four expansion tracks (reports/A-D) and
every harvest finished, including the two slow OTRRpedia passes (each program's
dated sponsors, each person's birth and death), which completed 2026-10-21 with no
failures.

| File | What |
|---|---|

Not included (re-fetchable): Track A's query cache, the CCE drama OCR and the magazine-renewal OCR (`magazines/raw`) |

Release, never in git (Decisions 017/018). No release upload was possible from the
session, so the snapshot rides this feature branch; move it to the radio app's own
repository (a Release, published from CI) and delete `dist/` before this branch merges.
