# Stuck playing

*Written by Claude, awaiting Ben's review.*

Playing is the move that makes your thinking tangible, and it is where
I have been stuck most often, because it is where the app, the agent,
and the tools all meet your actual device. Five of the six stuck
patterns in my own record live here ([research note 01](../../research/curriculum/01-mining-bens-process.md#where-i-got-stuck-and-what-got-me-out)),
and every one of them got better once I wrote down what I saw before
asking for another fix.

- [The agent fixes what I cannot see](cannot-see-the-fix.md)
- [The same bug keeps coming back](same-bug.md)
- [There is not enough real data](not-enough-data.md)
- [It works, and it still feels wrong](feels-wrong.md)
- [The agent keeps stopping](agent-stops.md)
- [The tools themselves are stuck](tools-stuck.md)

Two things apply to every page here. Git is your real safety net in
every tool, because Claude Code's checkpoints only track the edits
Claude made itself and "this isn't a replacement for git," and whether
Antigravity's rewind covers files changed by commands is not documented
([research note 03](../../research/curriculum/03-claude-code-and-antigravity.md#small-steps-and-getting-back)).
And the agent is never the tester: you are, on your device.

If none of these is your page, go back to [the ladder](../README.md#the-ladder-for-any-kind-of-stuck).
