# Screenshots of the agents

*Written by Claude, awaiting Ben's review.*

These pictures were taken on October 7, 2026, on Ben's Mac, in a demo
project (a local copy of this template called `reading-nook`, never
pushed anywhere), with Antigravity 2.19.1 and the Claude desktop app as
it was that day. Anything private, such as names, email addresses, other
projects, and usage numbers, was cropped out or left off the screen.
`tools/shot.sh` captures one app's window the same way, so a picture can
be retaken when an app changes.
