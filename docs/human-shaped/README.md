# Human-shaped software

I want anyone who builds with an AI agent to be able to say what they
are building, and why it is different. These pages are where that is
written down. They are the canonical texts behind humanshaped.org: the
website presents them, and this folder is where they change.

**Software that leaves people more capable.**

## The pages

| Page | What it is for |
|---|---|
| [Computer-shaped problems](computer-shaped-problems.md) | Software brain, the habit of seeing every problem as a database, and why human-shaped software uses AI as a tool for human purposes instead. |

| [HUMAN-SHAPED template](HUMAN-SHAPED-template.md) | The file you copy into your own repository to answer the principles one by one, which earns the Aligned with Human Shaped mark. |

## Where to start

If you are new to all of this, read `computer-shaped-problems.md`
first. If someone has asked you why you do not simply ask an AI to make
the app, send them `not-vibe-coding.md`. If you want to see what the
method looks like over months, read the case study.

When you are ready to build, the stages start at
[`../path/00-why-we-build.md`](../path/00-why-we-build.md).

## Writing these pages

Every page here follows `../maintaining/WRITING.md`. Every anchor is
real and traceable: a commit, a decision, a dated quote, a public post.
Nothing is invented, and numbers say how they were counted.

Read one page. Bring back one question.
